# Mivaku Commerce

**SKU Label Printer for Indian E-commerce Sellers**

Print your Master SKU + Quantity directly on marketplace shipping labels — instantly, offline, from all major platforms.

## Supported Platforms

- 🛒 Ajio
- 📦 Amazon
- 👗 Myntra
- 👶 FirstCry
- 🏷️ Snapdeal

## Features

- ⚡ Blazing fast — native desktop app, processes 1000+ labels in seconds
- 📴 Works 100% offline — no internet required for core operations
- 📊 Inventory & Stock Management with mobile barcode scanner
- 💾 Auto-backup with multiple safety locations
- 📈 Statistics & Analytics dashboard
- 🔒 Secure license system with hardware binding
